# VISUAL_EXPLORATIONS.md — 6 Filosofias de Design (revoa.me)

> **Explorações visuais** para a identidade tokenizada do revoa. Três **híbridas** (comunidade/calor
> humano + sopro cripto) e três **Web3** (on-chain/DeFi nativo). Cada uma é uma **filosofia estética**
> expressa em PNG (`docs/visual-explorations/`) e interpretada sobre os mesmos três elementos de marca:
> o **wordmark "revoa.me"**, o **monograma "RV"** e o **símbolo monetário "RM$"** (sem tagline).
>
> Base herdada do `trocadeira/VISUAL_IDENTITY.md`: paleta esmeralda `#10b981` / sky `#0ea5e9` /
> roxo `#a855f7` / rosa `#ec4899`; dark-first (`#0a0a0a` ink, `#171717` charcoal); Inter (→ WorkSans).
> Cada exploração **constrói sobre** ou **diverge** dessa base.

## Bloco A — Híbridas (comunidade + calor humano)

### 1. Circuito Vivo
**Filosofia:** a economia circular não é abstração — é movimento vivo. Coisas **revoam**: saem de
uma mão, ganham nova utilidade, pousam em outra. O visual fala em órbitas: arcos concêntricos que
orbitam um núcleo (o "RV"), sugerindo fluxo contínuo sem começo nem fim. A paleta mantém o gradiente
esmeralda→sky, mas o adiciona um **âmbar quente** (calor humano/comunidade) como acento de chegada.

A composição é radial: o monograma no centro, o wordmark curvado ou horizontal acima, "RM$" como
pequeno marcador orbital. Cada arco é desenhado com a precisão de um mestre relojoeiro — espaçamento
milimétrico, pesos de linha graduados. O resultado deve parecer um mecanismo vivo, trabalhado por
contless horas: orgânico sem ser mole, geométrico sem ser frio. A filosofia é **ciclo com alma**.

### 2. Bairro Solar
**Filosofia:** hiperlocalidade é pertencimento. O revoa nasce no bairro, no condomínio, na quarteirão.
O visual fala em **grade de mapa** com pinos de localização e raios (1/5/10/25 km) que irradiam de um
ponto. A paleta desloca o neutro para um **terracota solar** sobre fundo creme/ink — vizinhança, sol,
calor de porta a porta.

A tipografia wordmark é tipográfica-editorial (serifada leve), transmitindo confiança de "mercado
local estabelecido", não startup fria. O monograma "RV" vira um pino de mapa estilizado. "RM$" é o
"preço da banca". A composição deve evocar o olhar de cima de um bairro animado ao meio-dia — luz,
densidade, comunidade — meticulosamente cartografado.

### 3. Semente & Voo
**Filosofia:** transformação. Um produto parado é uma **semente** esperando o voo; um serviço ganha
novo propósito. O visual narra essa metamorfose: uma forma que começa como semente/gota e se dissolve
em **trajetórias de voo** (linhas curvas ascendentes, como asas estilizadas). A paleta é esmeralda
profundo + verde-lima de broto + um fio dourado de luz.

Aqui o pássaro (símbolo herdado) retorna — não ilustrativo, mas **cinético**: um gesto de asa em três
traços. O wordmark é fluido, o monograma encapsula a semente, e "RM$" é a "energia do voo". Cada
trajetória é desenhada com a paciência de um naturalista — curvas perfeitas, harmonia orgânica.
O artesanato deve transparecer em cada curva.

## Bloco B — Web3 (on-chain / DeFi nativo)

### 4. Malha On-Chain
**Filosofia:** a rede é a verdade. Cada nó é uma carteira, cada aresta é uma troca — tudo rastreável,
imutável, conectado. O visual fala em **malha de nós** (graph) sobre fundo ink profundo, com nós
esmeralda pulsando e arestas sky finas. Tipografia em fonte techy (Tektur), wordmark monoespaçado.

A composição é sistemática: o monograma "RV" é o nó central do grafo; "RM$" é o rótulo de um bloco.
Linhas de grade clínicas, marcadores de referência sistemáticos — como um diagrama de uma disciplina
imaginária que mapeia a economia circular. A precisão é de engenheiro: cada nó alinhado à grade, cada
aresta com peso correto. O resultado deve parecer um artefato científico — denso, paciente, revelador
sob observação sustentada.

### 5. Ledger Prismático
**Filosofia:** tokenização é refração. Um item se torna NFT/voucher e refrata em facetas — múltiplas
faces do mesmo valor. O visual fala em **prisma/facetas geométricas** que refletem a paleta
roxo→rosa→sky em gradientes cristalinos sobre ink. O wordmark aparece como corte prismático, o
monograma como gema facetada.

A composição usa triangulação/shards alinhados com precisão de ourives: cada faceta reflete luz de
uma direção, cada gradiente calibrado. "RM$" é lapidado como um cristal pequeno. Texto escasso,
clínico, integrado à arquitetura visual. A peça deve parecer joalheria digital — dolorosamente
trabalhada, iridescente, sem um pixel fora do lugar.

### 6. Pulso Subnet
**Filosofia:** precisão silenciosa da infraestrutura. Uma Subnet-EVM roda sob a superfície; o usuário
sente só o **pulso** — a linha de base, o sinal vital. O visual é **mínimo e suíço**: vasto negativo,
uma única linha de pulso/onda sutil atravessando, wordmark enorme e calmo, marcadores de referência
diminutos. Paleta ink + um único acento sky cirúrgico.

A composição é exercício de contenção: quanto menos, mais. O monograma "RV" é tipográfico puro;
"RM$" é um rótulo de dado clínico. Linha de base grade, alinhamento absoluto, respiração generosa.
Cada espaço em branco é uma decisão deliberada — o silêncio foi esculpido, não esquecido. O resultado
deve parecer um instrumento de precisão — confiante, sereno, irrefutavelmente expert.
